# Flux produits mesbonbons.net

Fichiers de flux produits au format Google (texte tabulé), régénérés à 7 h et 12 h (Europe/Brussels) à partir des pages produits publiques de https://www.mesbonbons.net. Ce dépôt ne contient que les flux ; les scripts et l'historique de stock sont tenus ailleurs.

- `feed.tsv` : flux Google Merchant Center (compte MesBonBons).
  Adresse : `https://raw.githubusercontent.com/yvesvandamme1975-sketch/mesbonbons-flux/main/feed.tsv`
- `feed-bing-meta.tsv` : flux Bing Merchant Center / Meta Commerce Manager (liste validée, disponibilité selon le dernier relevé de stock).
  Adresse : `https://raw.githubusercontent.com/yvesvandamme1975-sketch/mesbonbons-flux/main/feed-bing-meta.tsv`

Données uniquement publiques (déjà visibles sur le site). Mise en place par Aives Consulting pour Fladis le 2026-10-10.
